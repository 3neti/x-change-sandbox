# 07-design-language.md

# x-change Cockpit
## Design Language

### Version
Draft v1

### Purpose

This document defines the visual and experiential design language of the x-change Cockpit.

The objective is to establish a consistent visual identity that reflects:

- Financial operations
- Treasury management
- Institutional workflows
- Operational intelligence
- Auditability
- Trust

This document governs:

- Visual hierarchy
- Typography
- Density
- Color systems
- Data presentation
- Motion
- Interaction patterns

---

# Design Philosophy

## The Cockpit Metaphor

The x-change Cockpit is not a website.

The x-change Cockpit is not a CRUD application.

The x-change Cockpit is an operational workstation.

Users should feel like they are operating:

```text
Treasury
Settlement
Distribution
Funding
Intelligence
```

rather than browsing records.

---

# Design Inspirations

Primary inspirations:

```text
Bloomberg Terminal

Treasury Workstations

Trading Platforms

Operations Command Centers

Mission Control Systems
```

Secondary inspirations:

```text
Stripe Dashboard

Linear

Notion

Figma

Modern Banking Portals
```

Avoid inspiration from:

```text
Generic Admin Templates

Bootstrap Dashboards

Consumer Wallet Apps

Social Networks
```

---

# Visual Personality

The application should feel:

```text
Professional

Confident

Trustworthy

Dense

Efficient

Institutional

Modern
```

The application should not feel:

```text
Playful

Gamified

Toy-like

Cartoonish

Overly decorative

Overly minimal
```

---

# Information Density

## Principle

Professionals prefer information density.

The Cockpit should display:

```text
More information

With less navigation
```

without overwhelming the user.

---

## Density Levels

Workspace profiles may influence density.

### Executive

```text
Lower density

Larger metrics

More visual summaries
```

---

### Operations

```text
Medium density

Balanced visuals

Balanced tables
```

---

### Treasury

```text
High density

More tables

More financial metrics
```

---

### Compliance

```text
High density

Evidence-focused

Audit-focused
```

---

# Typography

## Typography Philosophy

Typography should communicate authority.

Not trendiness.

---

## Heading Levels

### Level 1

Used for:

```text
Dashboard

Funding

Pay Codes

Templates
```

---

### Level 2

Used for:

```text
Sections

Regions

Major Widgets
```

---

### Level 3

Used for:

```text
Cards

Subsections

Panels
```

---

## Numeric Typography

Financial values should receive special emphasis.

Example:

```text
₱125,000,000
```

must be visually dominant.

Numbers should be easier to scan than surrounding text.

---

Not merely containers.

---

## Examples

```text
Settlement Card

Risk Card
```

```text

```

---

# Tables

## Philosophy

Tables are first-class citizens.

This is a professional application.

---

## Requirements

Tables should support:

```text
Sorting

Filtering

Column Selection

Saved Views

Export

Bulk Actions
```

---

## Avoid

```text
Tiny tables

Cramped controls

Excessive pagination
```

## Philosophy

Motion should communicate state changes.

Not entertainment.

---

## Acceptable Motion

```text

Pipeline Progress
```

```text
Bouncing Elements

Playful Animations

Decorative Motion
```



---

# Guiding Statement

The x-change Cockpit should feel like a financial operations workstation where value is monitored, controlled, distributed, settled, and audited with confidence.

Users should feel:

```text
In control.

Informed.

Capable.

Trusted.
```

The design language exists to reinforce those feelings on every screen.
